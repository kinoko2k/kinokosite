Rule

きのこサーバー ルール

・このルールは、「きのこサーバー」(いか、とうサーバーといいます。)を、たのしむうえでのルールです。

・りようきやくとはちがい、MinecraftServerないでとりしまるルールです。

・あんしんしてプレイできるようなかんきょうづくりをめざしています。

・サバイバルサーバーなのでじゆうをもくひょうにルールをせいさくしています。



+ ほかプレイヤーのプレイをぼうがいしない

1. ほかプレイヤーにむだんでこうげきしない

2. ほかプレイヤーへのひぼうちゅうしょう・さべつ・ぼうげん・せっとう・きょうはく・きょうよう・ほかサーバーへのせんでんこういはしない

3. たいじんトラップをさくせいしない (ようがんやサボテンやTNTトロッコをあくいをもってせっちするこうい)

4. めいわくなチャットはつげんをしない (spamやtellでこじんわるくちなど)

5. なりすましやさぎこういはしない

6. こじんじょうほうのかいじなどはしない



+ とちやけんちくのしようルール

1. じぶんのとちはほごしなければならない (ほごされてないとちはかきの2,3ルールのたいしょうがい)

2. ほかプレイヤーのけんちくぶつをむだんでけんちく・かいちくしない (ほごがきいてるとちのみ)

3. ほかプレイヤーのとちをうばわない

4. 1チャンクないのエンティティ(Mobやあたまなど)は30こいないにおさえる

5. けんちくもくてきいがいのしようもくてきでこうはんいのとちをしゅとくするには、うんえいとそうだんしなければならない



+ サーバーうんえいへのぼうがいこういはしない

1. じょうじうごきつづけるクロックかいろやTT(トラップタワー)などはさくせいきんし

2. クロックかいろをさどうさせたままほうちやログアウトをしない

3. とうサーバーにたいしてアクセスをしゅうちゅうさせふかをかけるこういをしない



+ ふせいこういをしない

1. とうサーバーのサービスけいぞくにししょうがでるけいたいで、ふぐあいやぜいじゃくせいをちょうさまたはあくようするこういをしない

2. ほんらいのMinecraftでできないきょどうやアイテムゲットをしない

3. しようかのうなModはおもにけいりょうかModやにほんごにゅうりょくほじょModのみ

4. PvPようのClientをしようしサーバーにログインしない



+ そのほか (うんえいなど)

1. ルールにいはんしているプレイヤーは、ざつだんでさわがずおといあわせにほうこくする

2. ネザーやエンドのリセットをちゅうこくしたにもかかわらずアイテムがなくなったばあいは、ほしょうたいしょうがい

3. サーバーいがいのげんいんでアイテムがロストしたばあいもほしょうたいしょうがい

4. しょばつされたさいにプレイヤーのこうどうやけんちくぶつがしょうきょされるばあいがあります
